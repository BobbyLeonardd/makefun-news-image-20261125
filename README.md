Entry for [make.fun](https://make.fun)'s daily news-image bounty for Wednesday 25 November 2026.

`entry.png` is one 1024x1024 front page: the date set large, three lead stories, and
forty-eight dated one-line briefs across eight sections — the Middle East, Europe,
Asia-Pacific, the Americas, Africa, markets and energy, tech, and disasters and sport.
Every brief reports an event of that day, in some time zone.

Run it the way the grader does:

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts

The program copies `entry.png` into the output directory, so both grader runs write the
same bytes.
